# @design/component-hub

Zero-build headless atomic component snippets and anti-bleeding templates for Design Skill.

## Features
- **Anti-Bleeding Standards**: Built-in ≥12px Inset Padding, Surface Elevation Ramps, and Inset Track Shadows.
- **Top-Tier Alignments**: Modeled after Shadcn/ui, Radix UI, Tremor, and Semi Design.
- **Zero-Build Architecture**: Self-contained HTML and Tailwind snippets without Node build requirements.
