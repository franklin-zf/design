# Workflow

## Intake

Determine audience, reader job, use scenario, target surface, artifact type, delivery format, source materials, immutable constraints, and deadline. Ask only questions that materially change truth, shape, risk, or delivery.

When artifact type, goal, or use scenario is materially missing, present two or three concrete directions. Each direction names the output, intended reader outcome, scenario, and tradeoff. Recommend one, preserve known facts exactly, and wait for selection before substantial generation.

## Shape Selection

Choose one primary shape:

| Reader job | Shape |
| --- | --- |
| Read an argument with evidence | `data-report` |
| Monitor and inspect changing state | `dashboard` |
| Answer one quantitative question | `chart-frame` |
| Remember one message | `poster` |
| Follow a sequential presentation | `html-deck` or native `pptx` |
| Inspect UI evidence | `screenshot-evidence` |
| Explore meaningful parameters | `tweakable-artifact` |
| Reuse visual rules and components | `design-system` |

Use multiple artifacts only when reader jobs differ. Do not produce extra formats merely because tools exist.

## Narrative

Before visual design, write the one-sentence message, evidence order, caveats, desired action, must-keep facts, and prohibited claims. Decks additionally need a narrative arc; dashboards need default scan order; posters need one message and one visual hook.

## Responsibilities

- **Poster**: reader job, decision value, source-grounded message, evidence sequence, omissions, and non-claims.
- **Designer**: Taste Contract, visual system, hierarchy, typography, layout, media, components, and finish.
- **Reviewer**: source fidelity, exact numbers, logic, content ownership, visual defects, and assurance status.

These are responsibilities, not mandatory agents or files. Express and Standard work may execute them sequentially in one context. Use independent agents and durable handoffs only when the user requests them or Assured risk requires independent review.

## Default Sequence

1. Frame the reader job and shape.
2. Freeze source identity and immutable facts.
3. Build the narrative and claim structure.
4. Complete the Taste Contract and select the visual system.
5. Build the complete L0 static expression.
6. Add only justified interaction, motion, images, diagrams, or components.
7. Run applicable quality gates and inspect the real target surface.
8. Deliver the evidenced status and smallest next action.
