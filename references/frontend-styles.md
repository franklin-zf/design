## Borrowed Methods by Design Layer

This is a method map, not a template ranking or an upstream feature claim. The
H1-H5 hierarchy is owned by `references/design-standards.md`. Read the selected
asset only after its task fit is established; external network access is optional.

| Reference | Method to borrow | Design layer and destination | Do not import as a default |
| --- | --- | --- | --- |
| Open Design HTML PPT | Separate theme tokens, page layouts, and interaction runtime | H3/H4: existing profile, template catalogue, and deck rules | Its entire engine, effects catalogue, or historical demo content |
| Guizang PPT Skill | Sans-serif Swiss hierarchy, one selected functional accent, varied evidence rhythm, clean output without skill provenance copy | H2/H3/H4: production copy, type/color discipline, deck composition | Simultaneous theme colors, WebGL backgrounds, mandatory imagery, or magazine type in every business report |
| Taste Skill | Read audience, task, brand, and constraints before styling; reject automatic AI defaults | H2/H3: reader job and Taste Contract | Marketing-page density, asymmetry, or motion dial values on dashboards and formal reporting |
| Impeccable, prior research synthesis | Separate direction from finish; use detectors plus actual review and targeted repair | H5: existing Reviewer and review evidence | New command/agent hierarchies or a claim that its full runtime is installed |
| Emil Kowalski skills, prior research synthesis | Ask whether an effect is needed; use real-surface perception after mechanical checks | H4/H5: media job, static fallback, review | Universal animation quotas or UI interaction rules transplanted into static PPT |
| Open Design's Apple-inspired system | Neutral foundation, disciplined type, content/object emphasis, context-dependent density | H3/H4: concise-report defaults and hierarchy | Apple endorsement, SF Pro availability, marketing hero proportions, or negative tracking |
| React Bits / Aceternity UI / Uiverse | Selected motion or interaction implementation after a content job exists | H4 only: component admission, tokens and fallback | Aesthetic authority, whole-library installation claims, or component collages |
