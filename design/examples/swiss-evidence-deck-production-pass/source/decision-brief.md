# Evidence before style

The production promise is one source-backed, offline HTML deck whose claims, numbers, layouts, media, and review status can be inspected.

Open Design contributes 3 MIT-licensed execution files: the license, base CSS, and runtime JavaScript. Design owns the visual identity, semantic layouts, content hierarchy, and acceptance rules.

Standalone Guizang is used only as a reference for semantic layout discipline, projection legibility, image-slot truth, and visual rhythm. No Guizang template, motion implementation, demo copy, or distinctive selector is copied.

The first production fixture contains 9 slides. It requires 9 registered layouts and 9 source-backed slide rows. It does not claim native PPTX, PDF, Figma export, live data, or external fact verification.

Ready means the source hash, calculation code, deterministic test, derived output, visible content, responsive render, reduced-motion mode, and reviewer decision all pass their applicable gates.
