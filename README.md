# design

## 中文

一个将用户内容或数据转化为可信视觉产物的 Codex Skill，支持报告、仪表盘、图表、海报和网页演示。它优先保证来源真实性、可读性与内容相关的审美质量。

使用方式、质量门槛与能力边界见 [`SKILL.md`](SKILL.md)。

## English

A Codex skill for turning user content or data into trustworthy visual artifacts, including reports, dashboards, charts, posters, and web presentations. It prioritizes source fidelity, readability, and content-specific visual quality.

See [`SKILL.md`](SKILL.md) for usage, quality gates, and capability boundaries.
